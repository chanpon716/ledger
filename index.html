連到你的 Google Sheet（只需做一次）
  1. 打開程式編輯器：
    試算表 → 擴充功能 → Apps Script，或直接在瀏覽器開 script.google.com → 新增專案
  2. 刪掉裡面原有的程式，貼上下方程式碼
  3. 按 部署 → 新增部署作業 → 類型選 網頁應用程式
  4. 「執行身分」選我，「誰可以存取」選任何人 → 部署並授權
  5. 複製 網頁應用程式網址（結尾 /exec），貼到上面欄位並儲存
已經部署過？改完程式要「更新」才生效
部署 → 管理部署作業 → 點現有那筆的鉛筆圖示 → 版本選 新版本 → 部署。
網址不會變，不用重貼。改完後到上面按一次「測試連線」，要看到 v1.3.0 才算成功。

程式已內含你的試算表 ID，兩種方式貼都通用；會自動建立「收入」與「支出」兩張工作表。

之後在手機瀏覽器選「加入主畫面」，就會像 App 一樣全螢幕開啟。
